  - 목차: 1 Color / 2 Grid / 3 Breakpoint Scale(브레이크포인트 / 종횡비) / 4 Spacing & Sizing / 5 Effect (Radius/Shadow/Blur/Backdrop Blur/Opacity) / 6 Icon / 7 Typography. 목차 옆 설명이 "상품 상세, 메인, 요금, 고객사례"로 복붙되어 있어 **아직 내용이 채워지지 않았습니다.**

- **Patterns**: "여러 컴포넌트를 조합해 실제 화면에서 반복적으로 사용하는 UI 구조… Hero Section, API 상품 카드 목록, 문서 레이아웃, 코드 예제 영역, 요금 비교, FAQ, 콘솔 데이터 테이블 등". 단 목차는 Foundations 목차가 그대로 복사되어 있습니다.

- **Dev Components**: "REST/SOAP 배지, API Method 배지, 코드 예제 탭, 파라미터 테이블, 응답 예시, 에러코드 표, SDK 샘플 카드"와 "파라미터 표는 필드명, 타입, 필수 여부, 설명, 예시 값을 명확히 구분합니다", "에러코드는 코드, 메시지, 원인, 해결 방법을 함께 제공합니다", "REST API와 SOAP API는 배지나 탭을 통해 명확히 구분합니다"
- **Templates**: "상품소개 페이지는 도입 의사결정과 전환을, 개발자 문서 페이지는 빠른 연동과 기술 신뢰를, 콘솔 페이지는 운영 관리와 상태 확인을 목적으로 합니다. 따라서 하나의 템플릿으로 모든 화면을 통일하지 않고, 목적별 템플릿을 분리합니다." 템플릿 목록은 Main(상품 상세, 메인, 요금, 고객사례) / Dev Docs(REST/SOAP 문서, 오류코드, SDK) / Console(관리자, 파트너, 인증키, 통계, 설정) / Account(로그인, 회원가입, 약관, 인증)입니다. **Templates 가이드의 사용기준·주의사항은 Dev Components 문구가 그대로 복붙된 상태**입니다.

### 2.1 3대 가치(Pillars), 원문
"Design Concept – 왜 바로빌개발자센터 인가요?"
1. **오래 믿고 맡긴다** – "17년 동안 바뀌지 않은 이유 / 오랫동안 꾸준히 선택 받아온 검증된 안정성 때문입니다." → **신뢰도 (Trustworthy)**
