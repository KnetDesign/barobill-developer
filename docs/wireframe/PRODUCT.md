### 1.3 GEO 규칙

- 상품명은 공식 명칭 하나만. 메뉴 · 눈썹 · 정의 문장 · title이 같아야 함. title = `○○ API | 바로빌 개발자센터` (상품명 기준, H1은 메시지 문장).
- 숫자 · 목록 · 조건은 표와 완결 문장으로(카드 문구에만 있는 사실은 인용되기 어려움).
- **요금 비공개**: 사이트에 단가 공개 안 함. 파트너 등록 후 콘솔에서 확인. 과금 '구조'(건당 · 월정액 · 포인트 충전 · 기본료 유무)와 '파트너 등록 후 단가 확인' CTA만. 숫자 단가 자리 · 예상 금액 자리 · '대표 단가 공개' 제안 모두 삭제.
- 국세청 시스템사업자(41000022)와 표준인증은 **전자세금계산서에만**. 다른 상품 페이지에 쓰지 않음. 현금영수증 시스템사업자는 따로 있고 바로빌은 등록되어 있지 않음(사용자 확인 2026-11-18).
- 01 '운영 안정성' = 회사 전체 수치 **월 약 700만 건 API 호출**(2026 상반기 월평균).
- 용어(2026-11-19): 01 첫 기둥 = '운영 안정성'(메인 02-1 눈썹 '01 운영 안정성'과 같게). 띠 문구 = 'AWS 서울 리전 운영'(메인 02-1 칩과 같게).

### 5.1 1-2 현금영수증 발행 · `/api/cash-receipt`

- 푸는 질문: 얼마이고, 국세청에는 언제 들어가나. · 브레드크럼 `… › 발행`
- **Hero** 눈썹 `현금영수증 발행 API` · H1 `결제가 끝나면` / `현금영수증도 바로 발행하세요` (제안) · 리드 `주문·결제 시스템에서 현금영수증을 발행하고 국세청 전송까지 처리합니다.` · 정의 `바로빌 현금영수증 발행 API는 기업의 주문·결제 시스템에서 소득공제용·지출증빙용 현금영수증을 발행하고 국세청에 전송하는 API입니다. 발행 건당 과금하며 월 기본료는 없습니다.` · 띠 `월 기본료 없음` · `발행 건당 과금`. ('바로'는 발행 요청 시점 기준 — 국세청 전송은 다음 날)
- **01** 막힘없는 연동 `인증키 자동 발급 · 같은 인증키로 다른 API도 연동` · 부담 없는 비용 `월 기본료 0원 · 발행 건당`
- **02** `자사몰에서 결제 직후 발행` — `주문이 끝나면 바로 발행` / `입금을 확인하고 발행` — `계좌 통합 조회와 함께` / `플랫폼 판매자 명의로 발행` — `→ SaaS·플랫폼에 탑재`
- **03** 기능 카드(기능 화면): `소득공제·지출증빙` · `취소·부분취소` · `상태·이력 조회`

| 항목 | 내용 |

- **04** H2 `시작 절차` · 3단: `가입 · 파트너 등록` — `테스트·운영 인증키 자동 발급` / `테스트 발행` — `발행 → 취소 → 상태 조회 · 국세청 실전송만 빠짐` / `운영 전환` — `인증키와 API 주소만 바꾸면 운영 · 별도 신청 없음`. 코드 자리 `// REST · JSON 요청 예시 자리 — 발행 → 상태 조회 (가짜 엔드포인트 · 메서드명 금지)`

- **05** `전자세금계산서` — `사업자 고객에게는 세금계산서로` / `계좌 통합 조회` — `입금 확인 후 발행` / `홈택스 매입매출조회` — `신고된 현금영수증 내역 수집`

- **Hero** 눈썹 `홈택스 매입매출조회 API` · H1 `홈택스 매입·매출 자료를` / `매일 우리 시스템으로 받으세요` (제안) · 리드 `홈택스에 신고된 매입·매출 자료를 매일 우리 시스템으로 받아 옵니다.` · 정의 `바로빌 홈택스 매입매출조회 API는 홈택스에 신고된 매입·매출 세금계산서와 현금영수증 자료를 하루 한 번 수집해 제공하는 API입니다. 공동인증서 또는 홈택스 부서사용자 아이디로 연동하며, 월정액으로 과금합니다.` · 띠 `하루 1회 수집` · `공동인증서 또는 부서사용자 아이디` · `월정액 · 신청한 달 무료`. - **04** 4단: `가입 · 파트너 등록` — `테스트·운영 인증키 자동 발급` / `홈택스 연동 등록` — `인증서 또는 부서사용자 아이디` / `다음 날 수집 확인` / `운영 전환` — `인증키 · API 주소를 바꾸고 운영 환경에서 다시 신청`. (공통 표의 '홈택스에서 부서사용자 아이디 생성' 단계는 Stepper에 별도 없음 → 확인 필요)
