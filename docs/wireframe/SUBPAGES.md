## 8-1. 회원가입 (SSO, 신규) · `/signup`

- 목적: '테스트 시작하기'의 도착점. 바로빌 계정(SSO)으로 가입 → 이어서 파트너 등록 → 인증키 발급. **가입과 파트너 등록을 한 화면 2단계로**(계정만 만들고 멈추는 이탈 감소, 가설).
- 레이아웃: Sign-in and Registration › Split screen. 왼쪽 혜택 · 오른쪽 폼. 단계 표시 `UStepper`(2단, 작게).

### 왼쪽
- H1 `파트너 등록까지 마치면` / `인증키가 바로 발급됩니다` (제안)
- `01 테스트 · 운영 인증키 자동 발급` · `02 테스트 포인트 1만 점 자동 지급` · `03 가입과 파트너 등록은 무료`
- `문서만 보려면 가입하지 않아도 됩니다 · API 개발 문서` (링크)

### 오른쪽
- 단계 `1 / 2 바로빌 계정` · `2 / 2 파트너 등록`
- 1단계: `UAuthForm`(providers = 1개, fields 없음) 버튼 `바로빌 계정으로 계속하기` · 안내 `바로빌 계정이 없으면 같은 화면에서 만듭니다` · `SSO 화면 · 항목 확인 필요`
- 2단계 `2단계 · 파트너 등록` (`UForm`):

| 라벨 | 컨트롤 | placeholder/옵션 |
|---|---|---|
| 회사명 | UInput | 회사 이름 |
| 사업자번호 | UInput | 000-00-00000 |
| 어떻게 쓰실 건가요? | URadioGroup(variant card, 2개) | `우리 회사 업무에` / `우리 고객에게 제공` · 도움말 `나중에 바꿀 수 있습니다` `확인 필요` |
| 동의 | UCheckbox | `이용약관 · 개인정보처리방침에 동의합니다 (필수)` |
| 소식 | UCheckbox | `바로빌 소식 받기 (선택)` |

- 제출 `파트너 등록하고 인증키 받기`
- '가입코드' 칸 그리지 않음(막힘 원인, 간소화 요청). 남겨야 하면 2단계 선택 칸으로.
- 2택은 상황별 솔루션 두 축과 같음 — 가입 직후 안내 문서를 나누는 데 씀(제안).
- 반응형: md 미만 폼 카드 안쪽 48 → 24, 2열 입력 1열, 왼쪽 혜택은 폼 위 한 덩어리로.
- 확인 필요: SSO 범위(바로빌 본 사이트 계정과 같은지, 받는 항목 — 아이디 · 휴대폰 인증 · 사업자 정보), 파트너 등록 필수 항목 · 사업자번호 검증 방식 · 2택 변경 가능 여부, 약관 묶음.

## 8-2. 탈퇴 (SSO, 신규) · `/account/leave`

- 목적: 콘솔 › 계정 설정에서 들어옴. 탈퇴하면 무엇이 사라지는지 먼저 보여 주고 확인 후 처리.
- 레이아웃: 696 가운데 정렬 단일 폼 (Form Layouts + Modal Dialogs 경고형)
- 브레드크럼 `계정 설정 › 탈퇴` · H1 `개발자센터 탈퇴` · 리드 `탈퇴하기 전에 아래 내용을 확인해 주세요.`
- `UAlert`(color warning, variant outline, 목록) 제목 `탈퇴하면`:
  - `테스트 · 운영 인증키를 더 쓸 수 없습니다` `확인 필요`
  - `남은 충전 포인트 처리` `확인 필요`
  - `연결된 회원사는 자동으로 정리되지 않습니다. 회원사 탈회는 바로빌에 신청합니다.` (확정 문장)
  - `바로빌 계정(SSO)까지 함께 탈퇴되는지` `확인 필요`
- `탈퇴하는 이유 (선택)` — `USelect` `선택하세요 ▾` (선택지 확인 필요)
- `UCheckbox` `위 내용을 확인했고, 탈퇴에 동의합니다`
- 버튼 `취소`(variant ghost) · `탈퇴하기`(color error; 시안은 검정 채움이지만 실제는 위험 색)
- 동작: '탈퇴하기'는 체크박스를 켜기 전까지 비활성 → 누르면 `UModal` SSO 재인증(다시 로그인). 두 단계로 실수 방지.
- 반응형: md 미만 폼 카드 안쪽 48 → 24.
- 확인 필요: 인증키 폐기 시점 · 남은 포인트 환불(충전금 환불 미확정, 요금 안내 04와 같은 항목) · SSO 계정 탈퇴 범위 · 탈퇴 이유 선택지 — 개발팀 · 운영팀.
