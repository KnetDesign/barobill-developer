# 메인 페이지 빌드 스펙 (와이어프레임 p-main 정리)

> 출처: 와이어프레임 `p-main`(메인) + 문서 머리말. 카피는 모두 (제안) 단계. 아래 따옴표 안 문구는 원문 그대로.
> 표기: ⚠확인 = 원문에서 확인 필요/재동의/법무 등으로 표시된 항목 · ❓모호 = 원문끼리 어긋나 결정이 필요한 곳.

## 0. 공통 규칙

- 기준 폭 1440. 헤더는 좌우 32 풀폭, 본문 콘텐츠 1216(좌우 112), 12열 그리드(열 72 · 간격 32).
- 1440보다 넓으면 GNB 내용 최대 1376 가운데, 바깥 여백만 늘어남.
- 브레이크포인트(Tailwind): sm 640 · md 768 · lg 1024 · xl 1280 · 2xl 1536. 배치 단계: 모바일 <768 · 태블릿 768–1023 · 데스크톱 ≥1024.
- 좌우 여백: 모바일 20 · 태블릿 32 · 1280 이상 1216 가운데(05 FAQ 주석 기준).
- 타이포 토큰(원문 이름/크기): Display · H1 40/52 · H2 32/40 · H3 22/32 · Title 18/28 · Body 16/24 · Small 14/20 · Caption 12/16. 02 머리말은 문서 위계 H2지만 글자 40, 02-1~02-3 H2는 32.
- 컨셉 A / B 토글이 있음: 섹션마다 컨셉 공통 또는 A판/B판이 다름(아래 각 섹션 표시).
- 섹션 순서와 면: GNB(흰) → 01 Hero(DARK + 흰 로고 띠) → 02 WHY(흰) → 02-1(DARK) → 02-2(흰) → 02-3(흰) → 02-4(연한 면) → 03(흰) → 04(흰) → 05 FAQ(흰) → 06 CTA(DARK) → 푸터(연한 회색).
- md 미만 공통(02-1·02-2·02-3): 보이는 순서 = 눈썹·H2·서브 → 항목(아코디언·근거 칸·세로 단계) → 이미지·그래픽(4:3, 최대 높이 240, 이미지 위 노드는 이미지 바로 아래에 붙여 함께) → CTA·근거 줄·각주. DOM 순서는 그대로, 보이는 순서만 바꿈.
- 모든 섹션은 결국 '테스트 시작하기'(가입)로 이어짐. 가짜 데이터·가짜 값 금지. 장식 그라데이션은 면색으로 바꿔도 됨.
- 앵커: 가입 `#p-signup` · API 개발 문서 `#p-docs` · 요금 안내 `#p-pricing` · 이용문의 `#p-contact` · 제안서 다운로드 `#p-proposal` · 전자세금계산서 구축형 `#p-onprem` · 시작 절차 섹션 `#m02-4`.

## 1. GNB · 메가메뉴 · 모바일 서랍 (컨셉 공통)

**채택: 컨셉 A·B 모두 A안**(그룹 + 텍스트 링크 + 문서 카드 1장, REF-006 골격). 디자이너 권고 A.
다른 안: B = 상품 이름만 + 솔루션 6개에 아이콘·설명 줄(패널 640, 문서 카드는 모든 폭에서 상품 열 아래).

## 2. 01 Hero · DARK
