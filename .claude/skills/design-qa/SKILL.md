# design-qa

1. `npm run check` (토큰·레지스트리·타입).
2. dev 서버 실행 중 확인 후 `BASE_URL=http://localhost:3000 npm run qa:smoke -- --routes=<routes> --widths=360,640,768,1024,1280,1440,1920` → 실패(가로 넘침·콘솔 오류·HTTP) 수정.
3. `.qa/` 스크린샷을 직접 보고 시각 검수: 텍스트 잘림·겹침, 정보 위계, 여백 일관성, 다크모드 경계/대비, 브랜드 다크 섹션, 버튼 상태, 확정 디자인과의 차이.
4. 키보드: Tab 순서(메가메뉴 상품→솔루션→문서 카드), Enter/Esc, 포커스 링 보임. 아코디언 `aria-expanded`.
5. 100점 기준(UX 25 · 시각 20 · 기획 15 · 정보전달 15 · 시스템 10 · 반응형/접근성 10 · 개발 5)으로 근거와 함께 평가, 90 미만이면 재작업. 자체 평가는 실사용자 테스트를 대체하지 않음을 명시.
6. 결과를 `docs/PROJECT_STATUS.md` 검수 결과에 기록.
